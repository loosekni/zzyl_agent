# 错误码总表

> zzyl_agent 接口通用错误码与响应结构。维护人：Codex。

## 通用响应结构

### 成功

各接口的成功响应结构见对应文档（`agent.md` / `nursing.md`），无统一外壳，直接返回业务数据。

### 失败

FastAPI 默认错误响应结构：

```json
{
  "detail": "错误描述或错误数组"
}
```

校验失败时 `detail` 为数组，每项含 `type` / `loc` / `msg` / `input`。

## 错误码

| HTTP 状态码 | 含义 | 触发场景 | 是否已实现 |
|------------|------|----------|-----------|
| 200 | 成功 | 正常返回 | ✅ |
| 422 | 参数校验失败 | 请求体不符合 schema 约束（必填缺失、长度超限、类型错误、枚举非法值等） | ✅（FastAPI 默认） |
| 500 | 服务端内部错误 | LLM 调用失败、数据库异常等未捕获错误 | ⚠️ 待补全局异常中间件，目前返回裸 500 |
